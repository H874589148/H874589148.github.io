## 六、发现的差异

### 差异 1：SK 高通 R1/R2 位号命名与用户描述相反

**用户描述**：
> Vin—C1—A—C2—B→运放+，**R1：A—输出**，**R2：B—地**

**代码实现**（`tools/filter-design/topologies.js:21-28`）：
```javascript
// sk-hp 分支
branch('C1', vin, [260, 140]);           // Vin → C1 → A(260,140)
branch('C2', [260, 140], [480, 140]);    // A → C2 → B(480,140)
b.W([480, 140], op.plus);               // B → 运放+
branch('R2', [480, 140], [480, 290]);    // R2: B → 地
b.W([260, 140], [260, 30]);
branch('R1', [260, 30], [740, 30]);      // R1: A → 输出
```

**实测**：
- R1 从 A 接到输出（用户描述的 R1 位置）✅ 符合
- R2 从 B 接到地（用户描述的 R2 位置）✅ 符合

**结论**：经复核，代码实现与用户描述**一致**。BrowserAgent 报告为误判。✅ 无差异。

> 补充：HTML 公式说明（第 214 行）`SK 高通：H = (jω)²R₁R₂C₁C₂/(1+jωR₁(C₁+C₂)+(jω)²R₁R₂C₁C₂)` 与代码中 `rev-calc.js:79` 的 `A = R1*R2*C1*C2; B = w*R1*(C1+C2)` 一致。

### 差异 2：TT 文本输入标签页无草稿保护

**现象**：在"文本输入"标签页修改表达式但未点击"生成"时，点击"在电路编辑器中编辑此图"不会被拦截，仍生成 handoff token。

**影响**：
- 不影响图纸数据（文本输入未生成时画布保持上一次状态）。
- 与画布标签页的草稿保护行为不一致。

**结论**：⚠️ 设计边界，非阻塞缺陷。如需与画布一致，需补充文本输入 dirty 状态检测。

### 差异 3：截图未获取

**现象**：BrowserAgent 全程视口 hidden，所有截图失败。

**影响**：
- 视觉项（明暗主题、窄屏、字体重叠等）通过 DOM/CSS/代码验证，但**未提供实际截图证据**。
- 用户需手动在浏览器预览面板中复验。

**结论**：⚠️ 环境限制，非代码缺陷。

## 七、未验证边界

以下项目受自动化环境限制，**未实际验证**，不能视为通过：

1. **真实鼠标拖动体验**：器件拖动的吸附、重新连线、双击参数对话框的鼠标交互。
2. **真实键盘交互**：Ctrl+Z/Ctrl+S 在真实浏览器中的焦点行为。
3. **原生右键菜单**：编辑器右键菜单的弹出与选择。
4. **中键/Ctrl+点击新标签页**：浏览器自动化中 `target="_blank"` 被拦截，改为同标签导航。
5. **beforeunload 对话框**：真实浏览器的离开提示与确认。
6. **localStorage 配额失败**：无法模拟存储配额耗尽场景。
7. **真实字体测量**：Razavi renderer 使用无测量能力的估算路径，真实浏览器下文字与导线可能重叠。
8. **DPI data-focus 真实点击/键盘定位**：代码验证了映射逻辑，但未验证真实焦点环和键盘 Tab 顺序。
9. **并发标签页体验**：多个副本标签页同时打开的 sessionStorage 隔离。
10. **截图证据**：所有视觉项无截图，需用户手动复验。
