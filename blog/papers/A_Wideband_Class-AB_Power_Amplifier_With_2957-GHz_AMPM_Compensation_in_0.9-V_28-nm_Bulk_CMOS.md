> **原文**：*A Wideband Class-AB Power Amplifier With 29–57-GHz AM–PM Compensation in 0.9-V 28-nm Bulk CMOS*, M. Vigilante, P. Reynaert, IEEE JSSC, 2018.
> **TL;DR**：64-QAM 要求 EVM 优于 −25 dB，深 class-AB PA 在增益压缩前就因 AM-PM 跌线；本文把"输入电容随幅度漂移 → 级间网络失谐 → 相位旋转"这条链拆掉——PMOS 变容管正负互补对消 + 宽带匹配不给失谐机会，29–57 GHz 全程 |AM-PM| < 1.8°，6 Gb/s 64-QAM 直接放大不靠 DPD。

## 背景与动机

5G mm-wave（24–60 GHz）用 64-QAM（PAPR ≈8–10 dB）实现高谱效率，PA 成为整机线性瓶颈。系统级研究表明：5° 的 AM-PM 对 EVM 的伤害相当于 1 dB 增益压缩；EVM 须优于 −25 dB（10⁻¹⁰ BER 下留 3 dB 余量）。而深 class-AB 偏置下 AM-PM 在增益压缩点之前就很显著，迫使大功率回退；数字预失真（DPD）在宽带调制 + 大阵列规模下复杂度爆炸——动机是做"物理上线性"的宽带 PA。

### 宽带调制的特殊难点

单音 CW 提取的 AM-AM/AM-PM 行为模型在 RF BW >100 MHz 时严重失真、过于乐观。双音分析揭示 IM3 的三重来源：

1. $C_{IN}$ 与 $G_m$ 的三阶非线性；
2. **级联二阶非线性**也折进 IM3——二阶谐波电流走共模（CM），而差分 PA 的虚地帮不上忙，需在输入/输出设低阻偏置网络与二次谐波陷波，宽带下这两者都难做好；
3. 输出电流同时依赖输入与输出电压：0.9 V 供电禁用 cascode、深缩 CMOS 输出电导恶化，低频包络与二次谐波分量经相位不同的路径叠加，造成上下 IM3 不对称——即**记忆效应**。

### AM-PM 的两大物理来源

- **非线性 $C_{IN}$**：即使驱动级理想线性，PA 的非线性输入电容也在放大前就污染信号；$C_{GD}$ 被中和后 Miller 反射仍然把非线性的 $G_m$ 折进输入端。大信号下 $C_{IN,AV}$ 从 128 fF 漂到约 133 fF——窄带级间网络因此失谐，$Z_{IN}$ 与 $Z_{21}$ 的相位/幅度随信号摆动，直接输出 AM-PM/AM-AM；
- **非线性 $G_m$**：当基波负载非纯阻（如 class-J）或输出存在与基波相差 90° 的强二次谐波电压（高效率工作的常态）时，$G_m$ 对输出电压的非线性依赖使 $I_{fo}$ 随幅度变化。

## 关键方法

### 1. 线性化技术选型

对比五类方案：输入 PMOS 变容管（对消 NMOS $C_{IN}$ 非线性，$V_{cnt}$ 可调，代价增益约 1.8 dB）；互补 N-PMOS 放大器（$C_{GS}$ 与 $G_m$ 失真双对消，但不利于低压、mm-wave PMOS 建模难、输出 CM 电压不定需反馈环）；源极退化电感（换增益）；谐波陷波（滤波器 Q 限制有效带宽）；Sweet-spot 偏置（依赖 PVT，实验室漂亮、产品难用）。

本文选择 **PMOS 变容管 + 宽带级间匹配**的组合：前者在 0.9 V 下鲁棒可调，后者让网络"不给失谐机会"——宽带设计同时缓解增益随频率陡变（又一记忆效应来源）。

### 2. 变压器四阶滤波器：宽带阻抗变换与功分/合路

用耦合谐振器构成的变压器四阶网络同时完成：50 Ω 阻抗按 $1/n$ 缩放（$Z_{L,B} = Z_{L,A}/n$，代价跨阻 $Z_{21}$ 降为 $1/n$）、功率分配/合路、吸收版图寄生，且不引入任何有损元件。中心频率：

$$
f_o = \frac{1}{2\pi\sqrt{L_{O,P}(1-k^2)C}} = \frac{1}{2\pi\sqrt{L(1-k^2)(C_{O,S}+C_{O,PAD})}}
$$

关键设计变量是 $kQ$ 乘积：输出合路器需高 $k_O$ 保证低损耗（$k_O=0.8$ 时 $f_H/f_L = \sqrt{(1+|k_O|)/(1-|k_O|)} = 3$）；级间功分器取中等耦合 $k_{int} \approx 0.4$ 换宽带平坦——定量计算表明宽带化的 PAE 代价仅 0.04%（14.6% → 窄带 14.56% 的反向差），28 nm 的高 $g_m/f_t$ 让"宽带换线性"几乎免费。

### 3. 深缩工艺的版图现实

DRC 强制全片同向栅取向，mm-wave 优化功率管无法像旧工艺那样旋转 90°——变压器版图设计需迁就；输出合路器高 $k_O$ 与无超厚顶层金属的 Q 值限制共同决定高频段效率下滑。

## 实验结果与性能指标

28 nm 体硅 CMOS（无 RF 超厚顶金属），0.9 V 供电，PA/驱动偏置 135/90 μA/μm，核心面积 0.160 mm²：

| 指标 | 数值 |
|---|---|
| 增益 / $S_{21}$ −3 dB 带宽 | 20.8 dB / **29–57 GHz（65%）** |
| AM-PM @ $P_{1dB}$ | 26–58 GHz < 1.8°；调 $V_{cnt}$ 0.5–0.9 V 后 **< 1°** |
| 峰值 $P_{sat}$ / $P_{1dB}$（30 GHz） | 16.6 / 13.4 dBm |
| 峰值 PAE / PAE@$P_{1dB}$ | 24.2% / 12.6% |
| $P_{sat}$ 覆盖 >56% $BW_{-1dB}$ | 15.1 dBm |
| 群时延平坦度 | ±10.3 ps（20–54 GHz） |
| 64-QAM @34 GHz（1.5/3/6 Gb/s） | 平均 $P_{OUT}$ 10.1/8.9/5.9 dBm |
| 线性（无 DPD） | EVM 优于 −25 dB，ACPR 优于 −30 dBc |
| 谐波 @ $P_{1dB}$ | 二次 < −50 dBc、三次 < −39 dBc（26–58 GHz，无片外滤波） |

变容管控制电压 $V_{cnt}$ 提供了设计后手段：逐频点微调即可把 AM-PM 压到 1° 以内，同时可补偿 PVT 与模型误差。

## 个人思考与总结

- **"失谐式 AM-PM"视角很解渴**：许多 mm-wave PA 的相位失真并非器件本身"旋转"了相位，而是大信号改变了 $C_{IN}$、让窄带网络工作点漂移——把匹配网络做宽带，相位失真自然失去杠杆，这与 LDO 里"UGB 决定一切"异曲同工。
- **变容管是把"非线性"当资源用**：NMOS 的 $C_{IN}$ 非线性难消，干脆再引入一个反极性的 PMOS 变容管正负相抵，还附送 $V_{cnt}$ 调节旋钮——线性化不必是"消除非线性"，也可以是"配对非线性"。
- **kQ 乘积是变压器匹配网络的通用语言**：带宽（式 (8) 的 $f_H/f_L$）、损耗（式 (9)）、阻抗变换能力全被 $kQ$ 一维定调；"输出高 $k$ 低损耗、级间中 $k$ 换宽带"的分工值得在任何毫米波无源网络设计中复用。
