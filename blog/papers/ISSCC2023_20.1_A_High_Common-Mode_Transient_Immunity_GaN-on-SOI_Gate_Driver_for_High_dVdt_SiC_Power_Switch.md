> **原文**：*A High Common-Mode Transient Immunity GaN-on-SOI Gate Driver for High dV/dt SiC Power Switch*, S.-Y. Li, W.-C. Hung, T.-W. Wang, Y.-T. Hsu, K.-H. Chen, et al.（阳明交大/Chip-GaN/Realtek）, IEEE ISSCC, 2023.
> **TL;DR**：标题别读反了——是**用 GaN-on-SOI 工艺做栅极驱动器 IC**（GaN HEMT 快、耐温、可做浮动域），去**驱动 SiC MOSFET**（1700V 主功率管）。三个硬骨头各有一招：CMT 干扰让 RX 解调器失明 → CMCE 把共模电流"对消"而不是"滤除"；关断 SiC 要负压、外置 VEE 慢且费电 → 片上负压发生器与电平移位器合体；不同 SiC 的 Miller 平台位置不一 → FZVS 实时检测平台，按需切换驱动电流。最终 CMTI 282 kV/μs、延迟 7 ns，均优于变压器隔离方案。

## 背景与动机

- 1700V SiC（储能 PCS）比 800V/1200V 开关更快：dv/dt >100 kV/μs、di/dt >10 kA/μs。开关节点的高 dv/dt 经隔离屏障寄生电容 $C_{PAR}$ 产生共模电流：
$$I_{CM} = C_{PAR}\cdot\frac{dv_{SW}}{dt}$$
  灌入高压侧 TX；若 RX 端阻抗 $R_{1(2)}$ 大，共模偏移 $CMS = I_{CM}\cdot R_{1(2)}$ 会把解调比较器的 VIP/VIN 推出输入共模范围 ICMR——部分 CMT 周期内收不到正确控制信号，只能靠迟滞窗口容错限流运行。
- 低压侧：高 dv/dt 经 $C_{GD}$ 耦合到 SiC 栅极 → 误开通风险，需负压 VEE 关断；分立 VEE 为克服寄生电阻只能设得更负 → 效率降，且 R_PAR 拖慢放电、延长关断甚至短路失效。
- 隔离方案对比：变压器隔离 CMTI 好但占空比被再生驱动电压限 50%；电容隔离不受占空比限制——本文走电容隔离路线，难点就在 CMTI。

## 关键方法

### 1. 包络检测 + CMCE 共模电流消除（Fig. 20.1.2）

- 电容隔离 RX 链路：TIA 接收隔离电容传来的高频差分电流 $I_C/-I_C$ → 差分电压 $V_{OP}/V_{ON}$ → 高速比较器 → 解调/保护逻辑输出 V_PWM_DRV。
- **CMCE**：用三个 dGaN HEMT（QDN2/QRN1/QRN2，栅接 VP 节点）从 TIA 正输入提取 CMT 噪声 ICM；对称一路从负输入提取。无 CMT 时，流过输出电阻 $R_{P(N)}$ 的电流是 2I_C——差分信号加倍、增益更高；**CMT 时 IIP/IIN 同增 ICM，CMCE 向 VOP/VON 各注入等量 ICM**——净共模噪声为零。不是把噪声滤在小信号域，而是在电流域让它自相抵消。

### 2. 组合式低 I_Q 电平移位器 + 片上负压发生器（Fig. 20.1.3）

- V_PWM_DRV 低→高：MEE 关断、one-shot 信号 V_OS_R 诱导电流经 R_E7 开 QE7 拉低 V_GE4；V_LS_OUT 变高后 D1/D2 导通给 C_EE 充电至 V_EE=V_D2_ON；V_LS_OUT 低时 MEE 导通、D1/D2 截止、C_EE 放电 → V_EE=−6V。
- **VEE 在 −6V 与 V_D2_ON 间自动切换**，低压侧 GaN 开关 ML 靠它自开自关——对比文献 [4] 省掉一个驱动低压侧的电平移位器；电平移位器 QE1–4 直接挂 V_BOOT/V_GL、charge pumper 全摆幅驱动 QE1-2，解决 [4] 的低摆幅问题，I_Q 又低。

### 3. QDC 四象限驱动控制（Fig. 20.1.4）

- 分段固定驱动电流对不同 V_TH 的分立 SiC 不通用（Miller 平台位置不定）；dV_DS/dt 与 dI_D/dt 造成栅振铃。**QDC = FZVS（浮动零压传感）+ V_BOOT 跟踪电路**，实时找到 Miller 平台再调度电流。
- FZVS：比较器与逻辑的 VDD 接 V_BOOT、VSS 依次接 V_GL−V_TH 与 V_GL → 输出 V_ZERO 直接驱动 QH，**自身免电平移位器**；S1/S2 钳位 VN 到 V_GL 解决低压侧开通后的比较器过应力。
- Miller 平台检测：V_BOOT 跟踪电路让 V_SEN 平时跟踪 V_BOOT；SiC 进入 MP 后，V_SW 的压降经耦合出现在 V_SEN，被窗口为 V_BOOT−V_TH ~ V_BOOT−2V_TH 的双比较器捕获 → V_MILLER 拉低；V_SEN>V_BOOT−V_TH 时离开 MP、继续跟踪 V_BOOT。
- 电流调度：MP 之前用**最大驱动电流**把 V_GL 从 −6V 快充向 0V；MP 之后切到满值电流充到 V_DD2=20V——快开通、低损耗、抑制栅振铃三合一。

## 实验结果与性能指标

GaN-on-SOI 工艺；硅基 TX 芯片 + 高/低压侧 GaN-on-SOI RX 芯片。

| 指标 | 数值 |
|---|---|
| 被驱 SiC / 场景 | 1700V SiC MOSFET，隔离 DC-DC：VIN=1700V、f_SW=100 kHz、I_LOAD=20A |
| V_SW 实测 dv/dt | 109 kV/μs |
| 传播延迟（V_PWM→V_GL） | **7 ns**（优于对比项 [5][6]） |
| CMTI @25°C | +260 / −200 kV/μs（V_GL 扰动 2.24–2.3V / 1.08–1.12V，无异常动作） |
| **CMTI @225°C（CMCE）** | **+282 / −211 kV/μs**（对比表最高） |
| VEE 温漂 | 15%（−40°C → 225°C） |
| 效率 | VIN 800→1700V 保持 >90% |

## 个人思考与总结

- **"对消"优于"滤除"**：CMCE 不在比较器前加滤波（会牺牲速度），而是构造一条与共模电流等值反相的注入路径，让净扰动在输出节点归零——与站内 [混合 ET 调制器](JSSC2019_Wideband_Hybrid_Envelope_Tracking_Modulator_With_Hysteretic-Controlled_Three-Level_Switching_Converter_and_Slew-Rate_Enhanced_Linear_Amplifier.md)里 LA 消纹波、[HKUST EER-ES](JSSC2019_A_Multi-Loop-Controlled_AC-Coupling_Supply_Modulator_With_a_Mode-Switching_CMOS_PA_in_an_EER_System_With_Envelope_Shaping.md) 里多环交接同属一个哲学：**干扰处理越靠近其物理源头、越依赖物理对称性，带宽代价越小**。
- **Miller 平台检测让驱动电流"随需而变"**：与站内 [SRE 按压摆需求启用](JSSC2019_Wideband_Hybrid_Envelope_Tracking_Modulator_With_Hysteretic-Controlled_Three-Level_Switching_Converter_and_Slew-Rate-Enhanced_Linear_Amplifier.md)的逻辑一致——不按最坏情况常开大电流，而是实时检测工作点状态（SR 密度/Miller 平台），只在需要时投入大的驱动能力。QDC 把这个思想做进了功率开关的栅路径。
- **工艺即架构**：GaN-on-SOI 让 RX 芯片天然耐受高温（225°C 实测）与高压浮动域，FZVS"供电轨挂在被测节点上"这种设计只有在 HEMT 阈值低、SOI 隔离好的工艺上才可行——选工艺时就决定了能做什么架构。
