> **原文**：*An 83.4%-Peak-Efficiency Envelope-Tracking Supply Modulator Using a Class-G Linear Amplifier and a Single-Inductor Dual-Input-Dual-Output Converter for 200MHz Bandwidth 5G New Radio RF Applications*, C. Chen, X. Li, R. Hu, L. Cheng, ISSCC 2024（Paper 31.1）。
> **TL;DR**：ET 调制器的损耗 = 线性放大器的电流 × 它身上的压降；本文不压缩电流，而是压"压降"——低幅时 Class-G 换到低压轨、高幅时无缝升到高压轨，且用一颗电感同时完成四轨生成与灌电流回收。

## 背景与动机

5G NR 把包络带宽推到 200/300MHz，同时 PA 去耦电容达数百 pF、电压耐量要求 >5V。混合型 ETSM（宽带低效线性放大器 LA + 高效开关放大器 SA）中，LA 的源/灌电流乘以压降是主损耗：高频包络下去耦电容充放电电流可观，LA 还需大偏置电流把输出极点推高。快速 Buck、三电平滞环、能量回收等既有方案受限于电流检测速度与电路延迟，200MHz 下难以适用。

## 关键方法

**串联 Class-G 线性放大器**：AB-LA + PLDO/NLDO + 功率二极管 DP/DN。PLDO 与 AB-LA 共享差分包络输入、但偏置电流 $I_{BIAS\_P} > I_{BIAS\_AB}$：低幅时 $V_{OUT\_LA} < V_{DDL}-V_{DP}$，$V_{DD\_AB}$ 被钳位到 $V_{DDL}-V_{DP}$，AB-LA 电流改由低压轨经 DP 供给；高幅时 MP 导通，把 $V_{DD\_AB}$ 调节到 $V_{OUT\_LA}+V_{OS\_P}$。低幅时段省去的损耗为：

$$P_{save} = (V_{DDH}-V_{DDL})\times I_{LA} \quad\text{或}\quad V_{SSL}\times I_{LA}$$

轨切换在 200MHz 包络下需平滑无失真：AB-LA 与两只 LDO 带宽均 >250MHz；1V 器件做 cascode 增益级、2.5V/3.3V IO 器件堆叠耐压，Cascoded Miller 补偿把输出极点推向高频；低 $V_{th}$ 1V 器件把 LDO dropout 压到几十 mV。

**SIDIDO 变换器**：取代传统 buck-boost，以 $V_{BAT}$ 与 $V_{SSL}$ 为输入、$V_{DDL}$/$V_{DDH}$ 为输出。关键在于 $V_{SSL}$ 恒定从 LA 灌电流——该电流为电感 $L$ 励磁，实现电荷回收。五开关各由两只 2.5V 器件堆叠耐 4.5V；比较器式控制调节 $V_{SSL}/V_{DDL}$，峰值电流模决定 $V_{DDH}$ 占空比，四相 $\Phi_1$–$\Phi_4$ 分时完成励磁与两路输出放电。

## 实验结果与性能指标

| 指标 | 本文结果 |
| --- | --- |
| 工艺 | 65 nm CMOS |
| 包络带宽 | 200 MHz（NR 信号，5Ω\|\|200pF 负载） |
| 包络范围 | 1 – 5 V |
| 峰值效率 | 83.4% @ 2.4 W 输出、$V_{BAT}$=3 V |
| 对比基线 | 较 Class-AB LA + boost 架构提升最高 4.9% |
| 电源级 | SIDIDO 1 MHz/8.2 μH；SA 2 MHz/4.7 μH |

## 个人思考与总结

- 与其拼命减小 LA 电流（牺牲带宽/线性），不如让 LA "少跨压"——Class-G 的价值在高频大电容负载场景被重新放大。
- SIDIDO 把"灌到低压轨的电流"当作电感励磁来源，回收路径零额外器件，是双轨结构下免费的效率红利。
- LDO 与 AB-LA 共输入但偏置更高的钳位方式，回避了高速比较器+迟滞切换的延迟难题，是 200MHz 下仍能平滑换轨的根因。
