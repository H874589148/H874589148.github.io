# 电机 PWM 与 SVPWM 控制方法详解

## 1 引言

电机驱动的本质，是用功率变换器把直流母线电压"剁"成电机绕组所需要的交流电压。开关器件（MOSFET / IGBT / SiC / GaN）只能工作在通、断两种状态，无法直接输出连续可调的电压——PWM（Pulse Width Modulation，脉宽调制）就是解决这个矛盾的核心手段：通过调节开关脉冲的宽度，让输出电压的**平均值**等效于目标波形。

PWM 方法的优劣，直接决定了电机的转矩脉动、电流谐波、效率、噪声和母线电压利用率。在众多 PWM 方法中，应用最广的是 SPWM（正弦脉宽调制）和 SVPWM（空间矢量脉宽调制）。本文从基本原理讲起，重点拆解 SVPWM 的实现过程，并对两种方法做量化对比。

## 2 PWM 基本原理

### 2.1 面积等效原理

PWM 的理论基础是**面积等效原理（冲量等效原理）**：形状不同但冲量（电压对时间的积分）相等的窄脉冲，加在惯性环节（如电机绕组的电感）上时，产生的响应基本相同。

因此，只要把一个正弦波周期切成足够多的小片，每片用一个等面积、等宽度的矩形脉冲代替，电机"看到"的就是一个正弦电压。

### 2.2 占空比与平均电压

设母线电压为 Vdc，开关周期为 Ts，导通时间为 Ton，则占空比 D = Ton / Ts，一个周期内桥臂输出的平均电压为：

```
Vavg = D · Vdc
```

D 从 0 到 1 连续变化，Vavg 就从 0 到 Vdc 连续可调。让 D 按正弦规律变化，就得到了正弦平均电压——这就是 SPWM 的思路。

### 2.3 载波与调制波

工程上 PWM 由**比较器**产生：低频的调制波（想要的目标波形）与高频的三角载波比较，调制波高于载波时输出高电平，反之输出低电平。

- **开关频率 fs**：载波频率，常见 5 kHz – 20 kHz（避开人耳听觉范围）；SiC/GaN 方案可做到几十至上百 kHz
- **调制比 m**：调制波幅值与载波幅值之比，线性调制区内 m ≤ 1

fs 越高，电流纹波越小、控制带宽越高，但开关损耗和 EMI 也越大，且受限于器件开关速度与 MCU 算力。

## 3 SPWM：正弦脉宽调制

### 3.1 单极性与双极性

- **单极性 SPWM**：输出电平在 0 与 +Vdc（或 −Vdc）之间切换，谐波特性好，常用于单相逆变
- **双极性 SPWM**：输出在 +Vdc 与 −Vdc 之间切换，实现简单，谐波较差

### 3.2 三相 SPWM

三相逆变器（三相全桥）中，三相调制波互差 120°，分别与同一三角载波比较，得到三路 PWM 驱动三个半桥。相电压基波幅值最大为 Vdc/2，线电压基波幅值最大为 (√3/2)·Vdc ≈ 0.866 Vdc。

三相 SPWM 实现简单、概念直观，但有一个明显的短板：**直流母线电压利用率不高**。这引出了 SVPWM。

## 4 SVPWM：空间矢量脉宽调制

### 4.1 电压空间矢量

三相绕组在空间上互差 120°，任意时刻三相电压可以合成为一个旋转的空间电压矢量。SVPWM 不再逐相生成正弦 PWM，而是直接在**矢量层面**控制：让每个开关周期内逆变器输出矢量的平均效果等于目标矢量 Uref。

定义 Clarke 变换（αβ 静止坐标系）：

```
Uα = (2/3)·(Ua − Ub/2 − Uc/2)
Uβ = (2/3)·(√3/2)·(Ub − Uc)
```

### 4.2 八个基本电压矢量

三相全桥有 3 个半桥，每个半桥上管导通记为 1、下管导通记为 0，共 2³ = 8 种开关状态，对应 8 个基本电压矢量：

| 开关状态 (Sa Sb Sc) | 矢量 | 幅值 | 说明 |
| --- | --- | --- | --- |
| 100 | U4 | 2/3·Vdc | 有效矢量 |
| 110 | U6 | 2/3·Vdc | 有效矢量 |
| 010 | U2 | 2/3·Vdc | 有效矢量 |
| 011 | U3 | 2/3·Vdc | 有效矢量 |
| 001 | U1 | 2/3·Vdc | 有效矢量 |
| 101 | U5 | 2/3·Vdc | 有效矢量 |
| 000 | U0 | 0 | 零矢量 |
| 111 | U7 | 0 | 零矢量 |

6 个有效矢量把 αβ 平面分成 **6 个扇区**（每个 60°），构成一个正六边形。任意目标矢量 Uref 必然落在某个扇区内，可以用该扇区的两个相邻有效矢量加零矢量合成。

### 4.3 实现五步法

**第一步：扇区判断。** 根据 Uα、Uβ 的符号和相对大小判断 Uref 落在哪个扇区。工程上用三个中间变量快速判断：

```
A = Uβ
B = (√3/2)·Uα − (1/2)·Uβ
C = −(√3/2)·Uα − (1/2)·Uβ
N = sign(A) + 2·sign(B) + 4·sign(C)
```

N 与扇区的对应关系查表即得（N = 3,1,5,4,6,2 分别对应扇区 I–VI）。

**第二步：计算相邻矢量作用时间。** 由伏秒平衡原理，在一个开关周期 Ts 内：

```
Uref · Ts = Ux · Tx + Uy · Ty + U0(7) · T0
```

解出相邻两个有效矢量的作用时间 Tx、Ty，剩余时间 T0 = Ts − Tx − Ty 由零矢量填充。若 Tx + Ty > Ts（过调制），需按比例压缩。

**第三步：确定矢量切换点。** 将 Tx、Ty、T0 分配到三相，得到各相的比较值（占空比）。

**第四步：生成开关序列。** 常用**七段式对称序列**（以扇区 I 为例）：

```
U0 → U4 → U6 → U7 → U6 → U4 → U0
```

序列关于周期中点对称，每次切换只动一个桥臂，开关次数最少、谐波最优。零矢量 U0 与 U7 各占 T0/2。

**第五步：输出 PWM。** 把各相比较值写入定时器比较寄存器，由硬件生成带死区的互补 PWM。

### 4.4 为什么母线利用率更高

SVPWM 线性调制区的上限是 Uref 幅值等于六边形内切圆半径，即 Vdc/√3 ≈ 0.577 Vdc（相电压基波幅值），而 SPWM 只有 Vdc/2 = 0.5 Vdc。

两者之比为 2/√3 ≈ 1.1547，即 **SVPWM 的直流母线电压利用率比 SPWM 高约 15.47%**。

物理本质是 SVPWM 在三相调制波中自动注入了三次谐波零序分量——它不出现在线电压中，却把调制波的峰值"压"了下来，腾出了调制空间。从这个角度看，SVPWM 等价于"注入三次谐波的 SPWM"。

## 5 SPWM 与 SVPWM 对比

| 维度 | SPWM | SVPWM |
| --- | --- | --- |
| 母线电压利用率 | 低（相电压基波幅值 ≤ Vdc/2） | 高约 15.47%（≤ Vdc/√3） |
| 电流谐波 / THD | 较高 | 较低，同开关频率下谐波特性更优 |
| 开关损耗 | 基准 | 七段式每次只切一相，损耗更低；五段式（DPWM）可再降约 1/3 |
| 实现复杂度 | 低，三路正弦比较即可 | 高，需坐标变换、扇区判断、时间合成 |
| 适用场景 | 简单逆变、UPS、低成本方案 | FOC 电机驱动、伺服、新能源车电控 |

## 6 工程实现要点

- **死区时间**：同一桥臂上下管绝不能同时导通（直通 shoot-through），互补 PWM 之间必须插入死区，典型 100 ns – 1 µs（随器件速度而定）。死区会引入电压畸变与基波损失，高速器件（SiC/GaN）可显著压缩死区，这也是器件选型时的关键指标
- **开关频率选择**：在电流纹波、开关损耗、EMI、控制延迟之间折中；频率越高电感/滤波器可越小，但损耗近似线性上升
- **过调制与方波模式**：需求电压超出线性区时进入过调制，波形畸变增大；极限是六步方波，母线利用率最高但谐波最严重
- **采样同步**：电流采样宜在 PWM 周期中点（零矢量中点）触发，避开开关噪声，读到的是平均电流
- **最小脉宽限制**：栅极驱动与器件存在最小有效脉宽，过窄的脉冲要么丢失要么畸变，需在软件中做脉宽钳位

## 7 总结

PWM 是连接数字控制器与功率开关的桥梁，面积等效原理是其统一内核。SPWM 以正弦调制波直接比较生成，简单直观；SVPWM 上升到电压空间矢量层面，用八个基本矢量合成目标矢量，换来约 15.47% 的母线利用率提升、更低的谐波与开关损耗，代价是实现复杂度。现代电机 FOC 控制中，SVPWM 已是事实标准；理解它，也就理解了逆变器输出能力的边界。
