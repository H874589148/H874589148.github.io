> **TL;DR**：SAR ADC 输出端的噪声是七类独立来源的正交叠加：量化噪声、采样 kT/C、比较器判决噪声、CDAC 与参考电压噪声、开关电荷注入的随机分量、时钟抖动、电源与串扰耦合。本文逐项推导计算公式、给出数值代入示例，并给出"以 LSB 为单位的分项预算表 → 合成 SNR/ENOB"的完整计算流程。

## 1. 噪声预算总框架

SAR ADC 没有级间增益放大器，所有误差源都"直接"进入输出码，因此噪声预算必须逐项核算后正交叠加：

$$\sigma_{tot}^2=\sigma_q^2+\sigma_{smp}^2+\sigma_{cmp}^2+\sigma_{dac}^2+\sigma_{inj}^2+\sigma_{jit}^2+\sigma_{ps}^2$$

| 来源 | 物理机理 | 一阶计算 | 主导设计变量 |
| --- | --- | --- | --- |
| 量化噪声 | 码格化的固有截断 | Δ²/12 | 分辨率 N |
| 采样 kT/C | 开关热噪声被 RC 带限 | kT/C（单端）、2kT/C（差分） | 采样电容 |
| 比较器噪声 | 输入对热噪声 + 全带混叠 | (8kTγ/gm)·(π/2)·fp | gm、判决带宽 |
| CDAC/Vref 噪声 | 参考通路噪声按码权进入 | 码权平方和 ≤ 1/3·vref² | 缓冲噪声、去耦 |
| 电荷注入/时钟馈通 | 开关沟道电荷与耦合 | WLCox·ΔV/2C、Cov/(Cov+C) | 开关结构 |
| 1/f 噪声与失调 | 慢相关偏移 + 随机失配 | 自稳零后 kT/C/A² | 工艺、校准 |
| 时钟抖动 | 孔径不确定性调制输入 | (2πf·σt·A)²/2 | 时钟链积分抖动 |
| 电源/串扰 | 经 PSRR 与耦合进入 | v_sup/PSRR、耦合电容分压 | 版图、隔离 |

工程准则：**全部电路噪声功率合计控制在量化噪声功率的 50%–100% 以内**（即下文的 Σr² ≤ 0.5–1），对应 ENOB 损失约 0.3–0.5 bit；超过 2 倍量化噪声功率（3 dB）通常意味着电容/功耗花费错了地方。

## 2. 量化噪声：一切预算的基线

假设量化误差在 ±Δ/2 内均匀分布：

$$\overline{e_q^2}=\int_{-\Delta/2}^{\Delta/2}e^2\,\frac{1}{\Delta}\,de=\frac{\Delta^2}{12},\qquad \sigma_q=\frac{\Delta}{\sqrt{12}}$$

对满幅正弦输入（RMS = V_FS/2√2，V_FS = 2ᴺΔ）：

$$\mathrm{SNR}_q=6.02N+1.76\ \mathrm{dB}$$

后续所有电路噪声都建议折算成与 σ_q 的比值（下文的 r_i = σ_i√12/Δ），使各项预算可以同一把尺子比较。

## 3. 采样保持与 CDAC 的 kT/C 噪声

### 3.1 一阶推导：与电阻无关的谱积分

导通开关电阻 R 的热噪声 4kTR 经 RC 低通后落在采样电容上：

$$\overline{v_n^2}=\int_0^\infty\frac{4kTR}{1+(2\pi fRC)^2}\,df=4kTR\cdot\frac{\pi}{2}f_p=\frac{kT}{C},\qquad f_p=\frac{1}{2\pi RC}$$

噪声带宽 πf_p/2 与 R 成反比、噪声谱密度与 R 成正比，两者相乘后 **R 消失，只余 kT/C**。这就是著名的采样热噪声下界，也是 SAR 热噪声-功耗极限分析的起点。

### 3.2 差分结构

两条采样支路噪声独立，差分输入参考噪声功率相加：

$$\overline{v_{n,diff}^2}=\frac{2kT}{C_{per-side}}=\frac{2kT}{C_{tot}/2}$$

其中 C_tot 为差分总采样电容（CDAC 顶板采样时 C_tot 即阵列总电容）。**SAR 的采样 kT/C 由 CDAC 电容直接决定，这是"面积/功耗 ↔ 噪声"核心权衡的来源。**

### 3.3 驱动源贡献

驱动电路（前级滤波器/PGA）的输出噪声被同一采样网络带限后叠加：

$$\sigma_{smp}^2=\frac{kT}{C}+\int_0^\infty S_{src}(f)\cdot\frac{1}{1+(2\pi fR_{tot}C)^2}\,df$$

若前级本身是采样电路，其 kT/C 直接与本级相加；前级为运放时按其输出噪声谱 × 采样网络传递函数积分。

### 3.4 R_on 调制的修正

开关导通电阻随输入电压调制（R_on ∝ 1/(V_GS−V_th)），严格来说噪声积分随信号变化，且产生谐波失真。工程处理：

- 噪声核算取 **R_on 最大值**对应情形，得到保守上界；
- R_on 调制主要按 **THD** 单独核算（自举开关可将其压低），与噪声预算分列。

### 3.5 预算换算与数值示例

要求 σ_smp ≤ α·Δ/√12（α 典型取 0.3–0.7），反解电容下限（差分、每边 C）：

$$C\ \ge\ \frac{2kT}{\left(\alpha\,\Delta/\sqrt{12}\right)^2}$$

**数值例**：N = 12，V_FS = 2 V（差分，每边 1 V），T = 300 K（kT = 4.14×10⁻²¹ J），α = 0.5：

- Δ = 2/4096 ≈ 488 µV，量化 RMS = 141 µV
- 允许差分 kT/C RMS = 0.5 × 141 ≈ 70.5 µV
- 每边电容 C ≥ 2 × 4.14×10⁻²¹ / (70.5×10⁻⁶)² ≈ **1.7 pF**

对应的 CDAC 单位电容、面积、建立时间与 Vref 抽取电荷全部由此"噪声 floor"向下游传导。

## 4. 比较器噪声

### 4.1 判决模型与翻转概率

每次位判决输出 sgn(v_res + v_n)，v_n 为等效输入噪声。噪声近似高斯时，余量为 v_res 处的误判概率：

$$P_{flip}(v_{res})=\frac{1}{2}\,\mathrm{erfc}\!\left(\frac{|v_{res}|}{\sqrt{2}\,\sigma_{cmp}}\right)$$

例：|v_res| = 3σ 时翻转概率约 0.13%。该式也是**码密度测量**的理论基础——噪声把理想码转移函数用 N(0, σ_cmp) 卷积模糊。

### 4.2 等效输入噪声计算

静态比较器（差分对 + 电流镜负载）输入参考差分噪声谱：

$$S_{n,in}(f)=\frac{8kT\gamma}{g_m}\cdot\frac{1}{1+(f/f_p)^2}$$

- 8kTγ/g_m：两输入管不相关叠加（单管 4kTγ/g_m）；
- 镜像负载再乘 (1 + g_m,L/g_m)² 修正；
- f_p 为输入节点极点。

判决近似瞬时采样，全部噪声带宽混叠进单次判决：

$$\sigma_{cmp}^2=\int_0^\infty S_{n,in}(f)\,df=\frac{8kT\gamma}{g_m}\cdot\frac{\pi}{2}f_p$$

**数值例**：g_m = 0.5 mS，γ = 2/3 → S_n = 4.4×10⁻¹⁷ V²/Hz（6.6 nV/√Hz）。若目标 σ_cmp = 0.25Δ ≈ 122 µV（12-bit）：

- 所需等效噪声带宽 ENBW = σ²/S_n ≈ 340 MHz
- 对应输入极点 f_p = ENBW × 2/π ≈ 216 MHz

低噪声比较器 ⇒ 大 g_m + 高带宽 ⇒ 功耗是根本代价；这正是 SAR 功效极限中比较器项的物理含义。

### 4.3 判决窗平均修正（sinc²）

更精细的模型：再生/放大时间 t_c 内噪声被时间平均，高频贡献衰减：

$$\sigma_{cmp}^2=\int_0^\infty S_{n,in}(f)\cdot\mathrm{sinc}^2(f\,t_c)\,df,\qquad \mathrm{sinc}(x)=\frac{\sin(\pi x)}{\pi x}$$

白噪下该积分给出 ENBW = 1/(2t_c)（t_c = 1 ns → 500 MHz）。此修正**只减不增**，预算时按 4.2 的全带积分取保守值即可。

### 4.4 对输出码的影响：负反馈与冗余

- SAR 逐位负反馈：某位误判后余量反号，后续位继续逼近真实值，**位权不净放大判决噪声**，输出端等效噪声仍 ≈ σ_cmp 量级；
- 无冗余设计准则：σ_cmp ≲ Δ/2——余量 |v_res| ≥ 3σ 的判决几乎不错，码沿附近的模糊表现为 ±1–2 LSB 的 DNL 毛刺；
- 冗余位（radix < 2，如 1.875，或 error feedback）把单次判决可容忍的噪声放宽到 Δ_eff 量级，同时消除大错码。

### 4.5 亚稳态

再生增益有限且判决时间有限，当 |v_res| < V_meta（正比于 $e^{-t_c/\tau}$）时输出不确定。工程对策：加大再生时间、放慢判决速率、级联第二锁存器、输出用格雷码/冗余吸收。亚稳态与噪声在预算中合并为"判决不确定性"核算。

## 5. CDAC 电容阵列与参考电压噪声

### 5.1 阵列自身的热噪声

顶板采样结构中 CDAC 电容就是采样电容，其 kT/C 已在 §3 计入，不重复计。底极板切换开关的 kT/C 经电容分压（系数 ≈ C_bot/(C_bot+C_tot)，平方后 << 1）耦合到顶板，通常可忽略；底极板切换瞬间节点被 Vref/GND 低阻驱动，开关噪声大部分被短路。**真正需要核算的是参考通路。**

### 5.2 Vref 噪声的两种机制（关键区分）

DAC 判决电压 = V_ref · Σb_i·C_i/C_tot，参考噪声按两种机制进入：

**（a）低频相关噪声**（带隙、LDO、缓冲器 1/f）：整个转换窗内近似恒定，按当次码权线性进入，最坏为 MSB 权 1/2：

$$\sigma_{out}=v_{ref,n}\cdot\frac{C_{msb}}{C_{tot}}\le\frac{v_{ref,n}}{2}$$

由于系数码相关，此类噪声部分表现为**增益类非线性（谐波）**而非纯白噪。

**（b）逐判决独立噪声**（缓冲器宽带热噪声）：各次判决独立平均，按码权平方和衰减：

$$\overline{\sigma_{dac}^2}=\overline{v_{ref,n}^2}\sum_i\left(\frac{C_i}{C_{tot}}\right)^2\le\frac{\overline{v_{ref,n}^2}}{3}$$

（二进制权平方和 1/4 + 1/16 + … = 1/3）

结论：Vref 链路在转换窗内的噪声几乎不衰减地进入输出。**大去耦电容**把宽带成分压掉（机制 b → 0），剩余低频成分按机制 (a) 核算；预算上 Vref 缓冲噪声通常要求 < 1/2 LSB 的输入参考当量。

### 5.3 参考缓冲建立残差

每次位切换从 Vref 抽取 ΔQ ≈ C_i·V_ref，缓冲器带宽 f_buf 在时隙 t_s 内的建立残差比例 ε = e^(−2πf_buf·t_s)：

$$v_{err}\approx\frac{\Delta Q}{C_{tot}}\cdot\epsilon$$

这是**码相关确定性误差**（失真项）；其随机分量（缓冲器噪声 × 建立窗）并入 5.2(b)。切换型/单调开关时序可减小抽取电荷的码相关性。

## 6. 开关电荷注入与时钟馈通

顶板采样开关关断时的两类确定性误差及其随机成分：

- 沟道电荷注入：$\Delta V_{inj}=\dfrac{WLC_{ox}\,(V_{DD}-V_{in}-V_{th})}{2C_H}$ —— 与输入相关（失真）+ 经 V_th 随机失配引入片间随机偏移；
- 时钟馈通：$\Delta V_{cft}=V_{clk}\cdot\dfrac{C_{ov}}{C_{ov}+C_H}$ —— 强确定性；
- 随机分量来源：σ_Vth = A_VT/√(WL) 的失配、沟道电荷分配涨落，Monte Carlo 仿真按等效输入失调折算。

抑制与代价：底极板采样（注入与输入解耦，化为固定失调）、全差分抵消偶次分量、dummy switch、自举开关（稳定 V_GS）。

## 7. 比较器 1/f 噪声与失调

- 1/f 噪声逐判决间**慢相关**：转换时钟 f_s >> 2f_c（转角频率）时逐判决近似独立，并入 σ_cmp 白噪核算；f_s << f_c 时偏移近似常数，表现为输出码的慢漂/谐波成分；
- 自稳零 / 相关双采样把 1/f 压低，代价是自稳零相引入的采样噪声经开环增益 A₀ 折算：$\sigma_{res}^2\approx kT/C_{az}/A_0^2$；
- 失调校准（DAC 微调/数字域）消除固定分量，校准分辨率决定残余失调；PMOS 输入对 + 大面积输入管从源头降低 1/f。

## 8. 时钟抖动

孔径不确定性 σ_t 对正弦输入（峰值 A）造成的幅度误差：

$$\sigma_{jit}=\frac{2\pi f_{in}\,\sigma_t\,A}{\sqrt{2}},\qquad \mathrm{SNR}_{jit}=-20\log_{10}(2\pi f_{in}\sigma_t)$$

**数值例**：f_in = 50 MHz（奈奎斯特）、σ_t = 0.3 ps、满幅（A = 1 V 每边）→ σ_jit ≈ 67 µV，SNR_jit ≈ 80.5 dB——对 12-bit（74 dB）刚好不构成瓶颈（r ≈ 0.47），但把 f_in 提高一倍即开始劣化。设计上用时钟链的**带内积分抖动**（积分到 f_in 频段）作为 σ_t。

## 9. 电源、衬底与串扰耦合

- 低频电源噪声经 PSRR 折算：v_out ≈ v_sup/PSRR，差分对高频 PSRR 恶化需按频段核算；
- **比较器再生期间电源噪声被 $e^{t/\tau}$ 指数放大**，是 SAR 对电源最敏感的窗口：对策包括再生前预充电到固定共模、判决期避开数字大电流活动、独立 LDO 供电；
- 数字时钟/逻辑经衬底与互容耦合到采样网络与比较器输入，表现为输入参考毛刺：深 N 阱、屏蔽线、敏感节点远离时钟走线；
- 计算方式：PSS + Pnoise 提取电源到输出的噪声传递，或抽取耦合电容后按分压线性折算。

## 10. 噪声合成与 ENOB 预算

### 10.1 合成公式

以量化噪声 RMS 归一的各分项 r_i = σ_i√12/Δ（量化项 r_q = 1）：

$$\mathrm{SNR}_{tot}=6.02N+1.76-10\log_{10}\!\left(1+\sum_i r_i^2\right),\qquad \mathrm{ENOB}=\frac{\mathrm{SNR}_{tot}-1.76}{6.02}$$

### 10.2 完整预算示例：12-bit 100 MS/s（V_FS = 2 V 差分，f_in = 50 MHz 满幅）

| 分项 | σ_i（µV RMS，输入参考） | r_i | r_i² |
| --- | --- | --- | --- |
| 量化（基线） | 141 | 1 | 1 |
| kT/C（C = 1.7 pF/边） | 70 | 0.50 | 0.247 |
| 比较器 | 60 | 0.43 | 0.181 |
| Vref/CDAC | 40 | 0.28 | 0.081 |
| 抖动（0.3 ps） | 67 | 0.48 | 0.226 |

Σr²（电路项）≈ 0.73：

$$\mathrm{SNR}_{tot}=74.0-10\log_{10}(1.73)\approx 71.6\ \mathrm{dB}\ \Rightarrow\ \mathrm{ENOB}\approx 11.6\ \mathrm{bit}$$

### 10.3 反向设计流程

1. 由 ENOB 目标确定 Σr² 上限（如 ENOB 损失 ≤ 0.4 bit → Σr² ≤ 0.73）；
2. 按"增大电容/电流的面积功耗代价"在 kT/C、比较器、Vref 之间分配各 α_i；
3. kT/C → C_tot 下限（§3.5），同时锁定面积与 Vref 抽取；
4. 比较器噪声 → g_m 与判决带宽反解（§4.2）→ 比较器电流；
5. Vref 缓冲噪声 + 去耦电容值（§5.2/5.3）；
6. 抖动 → 时钟链 PLL 带宽与鉴相器噪声指标（§8）。

## 11. 测量与仿真验证方法

- **直方图法**：直流或慢斜坡输入，输出码分布标准差 σ_code × Δ = 输入参考噪声。输入短路（shorted-input）直方图只含比较器 + CDAC 噪声，用于与总噪声分项剥离；
- **正弦 FFT**：分离 SNR/THD；改变 f_in 观察 SNR 随 20log f_in 的下降斜率可标定抖动项；
- **瞬态噪声仿真**：transient noise Monte-Carlo 跑多次完整转换 → 输出码直方图（最贴近真实，含全部时变机制）；SC 网络可用 pnoise(sampled)；
- **比较器单测**：输入 DC 扫描 + 瞬态噪声统计翻转概率，反推 σ_cmp（对 4.1 式拟合）；
- **A/B 实验**：更换时钟源、加深 Vref 去耦、屏蔽输入走线，逐项定位主导噪声源。

## 13. SAR ADC设计CheckList

1. SAR CDAC中的开关，如果SAR CORE的参考电压范围发生了变化，bulk与pepi需要从avss_in修改为avss，如果建立速度不够可以考虑让开关的bulk电位跟着时序进行切换/对开关的阻抗进行仿真；
2. 节点建立速度仿真：各个节点建立时间确认pvt能建立到LSB/10；
3. SAR RDAC中的开关，如果SAR CORE的参考电压范围发生了变化，bulk与pepi需要从avss_rdac修改为avss；
4. 如果在输入buffer Auto-zero阶段就把采样电容接进来会将放大器的offset存储在采样电容上，为了避免这个问题，必须要在输入buffer Auto-zero阶段结束以后将采样电容接入，需要注意输入buffer Auto-zero阶段结束以后将采样电容接入时由于电荷注入和时钟馈通引入的采样误差；
5. 电容节点最好不要出现漏电，不然影响电荷守恒，可以在最差corner下逐个节点检查，看看有没有风险大的点，有的话需要做nonoverlap（根据翻转方向可以预测输入信号是多少的时候风险最大）；
6. 切换通道时需要注意驱动能力较弱的通道需要切换成非交叠的开关；
7. 通道中的开关设计跨电源域的，如TSNS从VDD_Core_A切换到VREF电源域，T型开关的第一个开关需要把P管去掉，要注意通道的输入电压范围；
8. 通道中最好使用T型开关以避免耦合干扰；
9. SAR CORE的输入电平在ADC不使能期间会被放大器闭环regulate到共模电平因此不可以下拉到ground；
10. 参考宙斯，直接连接到PAD上的MUX需要增加串联电阻，防止Latchup；
11. AZ控制信号和SMPL信号不能交叠；
12. 验证BGP给出的参考电压噪声是否可以满足设计指标要求；
13. 比较器的两级AZ控制信号避免出现竞争冒险；
14. DAC的控制逻辑，第一个bit的控制不能和比较器第一级的AZ有交叠。

## 14. 小结

- SAR ADC 的噪声预算 = 量化基线 + 六类电路项的正交和，全部折算到"输入参考 µV RMS"与 r_i = σ_i√12/Δ 两个尺度即可统一管理；
- kT/C 由 CDAC 总电容决定，是面积/功耗权衡的锚点；比较器噪声用全带积分作保守预算，冗余位是最经济的"放宽券"；
- Vref 噪声必须区分"低频相关"与"逐判决独立"两种机制，去耦电容是二者的转换开关；
- 抖动在高频满幅输入下最先吃掉 ENOB 余量；电源与串扰靠版图与电源域设计兜底；
- 所有预算最终以码直方图与 FFT 测量闭环验证，transient noise 仿真是流片前唯一能覆盖全部时变机制的核算手段。
