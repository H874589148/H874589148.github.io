> **TL;DR**：斩波的核心是一句话——**信号搬两次家，噪声搬一次家**。输入开关把低频信号调制到斩波频率 $f_{ch}$（此处放大器噪声已是白噪地板而非 1/f），放大后再用同一方波解调：信号经两次调制回到基带（$\pm1$ 平方为 1），放大器的失调与 1/f 噪声因注入点在两个调制器**之间**、只被解调器调制一次，被搬到 $f_{ch}$ 处滤掉。与自稳零相比，斩波不采样、不引入混叠噪声，白噪谱密度不变；代价是 $f_{ch}$ 处的纹波与开关电荷注入带来的残余失调。

## 1. 根本矛盾：失调与信号同频带

低频精密放大（传感、生物电、热电偶）里，放大器自身的失调电压 $V_{os}$ 与 1/f 噪声**就落在信号频带内**：

- $V_{os}$：CMOS 运放典型 1–10 mV，比很多传感器信号还大；
- 1/f 噪声：低频谱密度按 1/f 上翘，转角频率 $f_c$ 可达 100 kHz–1 MHz（CMOS）；
- 低通滤波无法分离同频带的噪声；trim/校准只能一次性消除静态失调，**温度漂移与时变 1/f 仍会回来**。

出路：频谱搬家——把信号搬到没有 1/f 的频率去放大，再搬回来。这就是斩波。

## 2. 工作原理推导

信号链：

$$x(t)\rightarrow \boxed{\times m(t)}\rightarrow \boxed{A\ (含\ V_{os},\,1/f)}\rightarrow \boxed{\times m(t)}\rightarrow \mathrm{LPF}\rightarrow y(t)$$

其中 $m(t)$ 为 ±1 方波（斩波频率 $f_{ch}$），由两对交叉开关实现。

**信号路径**：经两次调制

$$x(t)\cdot m(t)\cdot m(t)=x(t)\quad(\because\ m^2(t)=1)$$

——两次搬家等于没搬，信号完好回到基带。

**噪声路径**：$V_{os}$ 与 1/f 噪声在放大器输入端注入，即**位于两个调制器之间**，只被第二个调制器作用一次：

$$V_{os}\rightarrow V_{os}\cdot m(t)\ \Rightarrow\ \text{搬到 }\pm f_{ch},\pm3f_{ch},\dots$$

——失调变成了 $f_{ch}$ 处的方波，低通滤除。

**频谱全程**（按段观察）：

| 位置 | 信号 | 失调/1/f |
|---|---|---|
| 输入端 | 基带 0~BW | 基带（与信号混在一起） |
| 第一调制器后 | 搬到 $f_{ch}$ 奇次谐波 | 仍在基带 |
| 放大器中 | $f_{ch}$ 处被放大 | 基带注入（放大器自己的） |
| 第二调制器后 | **回到基带** | **搬到 $f_{ch}$** |
| LPF 后 | 基带保留 | 滤除 |

方波傅里叶展开 $m(t)=\frac{4}{\pi}\left[\sin\omega_{ch}t+\frac{1}{3}\sin3\omega_{ch}t+\dots\right]$ 只含奇次谐波，所以信号实际在 $f_{ch},3f_{ch},\dots$ 处都被放大——放大器带宽覆盖 $f_{ch}+BW_{sig}$ 即可。

**$f_{ch}$ 的选择**：必须高于放大器 1/f 转角频率 $f_c$——信号被搬到 $f_{ch}$ 处时，那里放大器的噪声应已是白噪地板。典型 $f_{ch}$：100 kHz ~ 数 MHz。

## 3. 与自稳零（Auto-Zero）的对比

| | Chopper | Auto-Zero |
|---|---|---|
| 机制 | 调制/解调（连续时间） | 采样失调到电容再扣除（离散时间） |
| 宽带白噪 | **不变**（无采样、无混叠） | **增大**（宽带噪声混叠回基带，PSD ≈ 增 √2~2 倍） |
| 失调消除 | 残余 µV 级（受电荷注入限制） | 残余 µV 级（受 kT/C 与注入限制） |
| 输出伪影 | $f_{ch}$ 处纹波 | 采样毛刺 |
| 信号带宽 | $<<f_{ch}$ | $<<f_{az}$ |

工程上常**组合**：chopper 消 1/f 与漂移，嵌套 auto-zero 进一步压低残余失调（chopper-stabilized AZ、ping-pong AZ 等架构）。

## 4. 非理想因素与对策

1. **斩波开关的电荷注入/时钟馈通**：注入失配经调制形成**残余失调**（普通斩波残余 1–10 µV）；对策：嵌套斩波（nested chopper，外圈低频斩波消内圈残余，可到 nV 级）、注入补偿开关时序。
2. **输出纹波**：解调后的 $V_{os}$ 是 $f_{ch}$ 方波，增益大时纹波可观。对策：**RRL（Ripple Reduction Loop）**——伺服环检测输出纹波并反馈抵消；采样保持陷波（同步采样在纹波过零点）；多相斩波。
3. **输入阻抗与偏置电流尖峰**：输入斩波开关周期性翻转，产生动态输入电流（瞬态 IB），对高源阻抗传感器形成误差电压；数据手册给的是平均值，驱动高阻源要按尖峰核算。
4. **信号带宽上限**：信号频率须远小于 $f_{ch}$，否则自身也被低通/混叠——斩波运放只服务低频精密场景。
5. **开关自身 1/f**：斩波开关位于信号路径上，其沟道 1/f 噪声直接进信号——好在开关过驱动大、面积可做大，贡献通常远小于放大级。

## 5. 典型实现形态

- **斩波运放**：输入斩波 + 输出斩波夹住增益级；零漂移运放（zero-drift）的主流实现之一；
- **斩波仪表放大器（CCIA）**：耦合电容隔断大共模 + 斩波消失调（见站内 [仪表放大器常见结构](in_amp_topologies.md)）；
- **斩波带隙/比较器/ADC 前端**：比较器输入对斩波消判决失调；ΔΣ ADC 第一级斩波消 1/f；
- **嵌套斩波**：高低频两圈斩波嵌套，残余失调压到 nV 级（计量级运放）。

## 6. 数值感

| 指标 | 普通 CMOS 运放 | 斩波运放 | 嵌套/RRL 斩波 |
|---|---|---|---|
| 输入失调 $V_{os}$ | 1–10 mV | 1–10 µV | <1 µV |
| 失调温漂 | 几 µV/°C | 10–50 nV/°C | nV/°C 级 |
| 低频噪声（0.1–10 Hz） | µV 级（1/f 主导） | ≈ 白噪积分（无 1/f 隆起） | 同左，纹波更低 |
| 代价 | — | 纹波、动态 IB、$f_{ch}$ 时钟 | 时序与面积复杂度 |

温漂改善的物理原因：失调与漂移是慢变量，**每个斩波周期都被重新搬出基带一次**——它们来不及累积。

## 7. 小结

- 斩波 = 位置不对称的调制：信号过两个调制器（搬回原地），噪声只过一个（搬走）；
- 与 auto-zero 的本质差异：斩波是连续时间调制不混叠噪声，AZ 是采样对消要付混叠税；
- 设计三件事：$f_{ch}>f_{1/f}$ 转角、纹波抑制（RRL/陷波）、开关注入（嵌套斩波/时序补偿）；
- 一句话记住：**信号搬两次家，噪声搬一次家**。
