仿真结果收集

整理仿真设置，或将规则表格截图在浏览器本地转换为可校对、可编辑、可导出的结果表。

按电路模块类别（Common / AMP / LDO / PowerStage / 自定义）填写仿真设置与后仿寄生提参类型，实时生成规范化记录；字段名与字段值可分别设置加粗、斜体和颜色。默认字段名黑体加粗、值楷体斜体，支持 Word、Markdown、LaTeX 三格式复制。填写内容及样式自动保存在本机，刷新后恢复。

仿真设置

R：寄生电阻；C：对地电容；CC：耦合电容，具体以提参工具定义为准。No R/C 仍属于后仿，仅表示不含上述互连寄生，不代表去除器件本征寄生。未选择时记录标注「待选择」。

此处记录仿真中加入的寄生数值（键合线、封装、走线等），与上方后仿「寄生提参」的提取类型含义不同。

条目名与内容均自由填写；条目名为空的行不会写入输出，但会保留在界面与本机存档中。

电压 / 温度选「自定义…」后可直接填写任意点或范围；顶部分类按钮切换模块类别，各类别已填内容切换后保留；设置自动保存在本机，刷新后恢复。

格式设置

所有字段名（黑体）
所有字段值（楷体）

仅重置样式，不清空仿真数据。预览颜色随日夜主题调整；Word / LaTeX 使用适合白底文档的固定配色，自动颜色输出为黑色。

格式化预览

Word / WPS 粘贴时请选择「保留源格式」，以保留字体与所选样式。Markdown 保留加粗、斜体，不支持颜色；LaTeX 输出样式命令，需 XeLaTeX / ctex，使用颜色时另需 xcolor 宏包。

本地 OCR：图片及识别文字不上传。仅支持单个清晰正向的规则矩形表，不支持合并单元格、倾斜照片、曲线提取。识别草稿，请核对工程数值；置信分数不等于正确率。
