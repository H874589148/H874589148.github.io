仿真结果规范收集

按左侧表单填写仿真设置，右侧实时生成「字段名黑体加粗 + 值楷体斜体」的规范化记录；一键复制为 Word（富文本，粘贴后保留字体样式）、Markdown 或 LaTeX 格式，直接贴入实验记录、报告或邮件。填写内容自动保存在本机，刷新后恢复。

仿真设置

电压 / 温度选「自定义…」后可直接填写任意点或范围；设置自动保存在本机，刷新后恢复。

格式化预览

「复制 Word 格式」写入富文本剪贴板：粘贴进 Word / WPS 后字段名保持黑体加粗、值保持楷体斜体；Markdown 与 LaTeX 为纯文本。
