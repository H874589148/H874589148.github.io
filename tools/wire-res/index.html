版图寄生计算

按走线段累加寄生电阻与对衬底电容：M1~M9/M_user 金属层预设（方块电阻与单位衬底电容均可手改）、温度修正，支持所有段同电流或逐段独立电流，实时显示段阻值/电容/压降与最差段瓶颈。

模型假设：

  • 纯直流方块电阻模型：R = Rs·(L/W)，不含趋肤效应、电感与转角修正；温度按 R(T) = R·(1+α·(T−27°C)×10⁻⁶) 线性修正（默认 α = 3000 ppm/°C）。
  • 对衬底电容按平板电容近似：Ci = L·W·Csub（走线面积 × 单位面积电容），仅含底板电容，不含边缘 / 侧壁电容与层间耦合。
  • 「层」下拉提供 M1~M9 典型量级的方块电阻与单位衬底电容预设（越厚的高层 Rs 与 Csub 越低），选择后自动带出默认值，仍可按工艺手册手改（手改后层标记为 M_user）。
  • 电流设置两种模式：所有段电流相同（串联模型，总压降 = I×Rtot）；各段电流不同（如树状供电路径，逐段填写电流，总压降 = Σ(Ii×Ri)，可先用「统一填充」赋初值再逐段微调）。
  • 过孔 / 接触电阻可作为一段加入：令 L = W（方块数 = 1），Rs 直接填单个过孔 / 接触的电阻值（单位 mΩ），Csub 留空即不计电容。
  • 填入电流后，压降最大的走线段会红色高亮，并在表格上方显示瓶颈提示。
