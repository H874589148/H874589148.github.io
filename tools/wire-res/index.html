版图寄生阻抗计算

按走线段累加寄生电阻：每段填写长度、宽度与方块电阻（支持金属层预设与温度修正），实时显示方块数、段阻值与占比；填入通过电流可同时得到各段压降、总 IR 压降与最差段瓶颈提示。

模型假设：

  • 纯直流方块电阻模型：R = Rs·(L/W)，不含趋肤效应、电感与转角修正；温度按 R(T) = R·(1+α·(T−27°C)×10⁻⁶) 线性修正（默认 α = 3000 ppm/°C）。
  • 过孔 / 接触电阻可作为一段加入：令 L = W（方块数 = 1），Rs 直接填单个过孔 / 接触的电阻值（单位 mΩ）。
  • 不同金属层方块电阻差异较大：「层」下拉提供 M1 / M2~M5 / MTOP 典型量级预设（80 / 40 / 15 mΩ/□），选择后自动带出 Rs，仍可按工艺手册手改（手改后层标记为「自定义」）。
  • 填入电流后，压降最大的走线段会红色高亮，并在表格上方显示瓶颈提示。
