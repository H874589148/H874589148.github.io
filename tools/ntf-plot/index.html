噪声传递函数（NTF）绘制

按 z 域分子/分母多项式系数（z⁻¹ 升幂）绘制 |NTF|² 频谱，输出带内积分噪声与峰值（Lee 准则参考）。

H(ejω) = (Σbk·e−jkω) / (Σak·e−jkω)，ω = 2πf/fs ｜ |NTF|²dB = 10·log₁₀|H|² ｜ 信号带宽 fB = fs/(2·OSR)

说明：

  • 系数按 z⁻¹ 升幂排列（DSP 标准约定）。例：1 -2 1 表示 (1−z⁻¹)²；1 -1 0.5 表示 1 − z⁻¹ + 0.5z⁻²。
  • 带内积分噪声功率 = 0 ~ fB 内 |NTF|² 的平均值，即量化噪声经整形后残留在信号带内的功率比例（相对平坦量化噪声归一化）。
  • Lee 准则（经验）：单比特 ΔΣ 调制器要求 max|NTF| ≲ 1.5（对应 |NTF|² ≈ 3.5 dB）。峰值扫描范围固定为 0 ~ fs/2，与显示范围无关。
  • 频率轴为线性刻度，600 点；dB 模式显示下限 -120 dB。
