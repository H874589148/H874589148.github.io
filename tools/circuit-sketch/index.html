电路示意图编辑器

面向论文绘图的轻量原理图编辑器：标准直线符号、10px 网格吸附、端口吸附连线（正交 / 斜线可切换），内置差分对 / 电流镜 / 5 管 OTA 模板，一键导出论文级 SVG / PNG / PDF。所有编辑自动保存在本地浏览器。

器件库

拖到画布，或点击放到中心

模板

点击插入画布中心，自动成组可整体拖动

画布（1600×1100，网格 10px）

快捷键与操作：

  • W 连线模式 / Esc 回选择模式或取消连线；连线时端点自动吸附 20px 内的器件端口（红圈提示），拐点自动走正交路径；工具栏「走线」按钮可切换为两点斜线。
  • R 旋转 90°，H/V 水平/垂直镜像；Ctrl+C/V 复制粘贴，Del 删除，Ctrl+Z/Y 撤销重做。
  • Ctrl+G 成组 / Ctrl+Shift+G 解组；空白处拖拽 = 框选；Ctrl+单击 = 多选。
  • 器件库下方的「模板」可一键插入差分对 / 电流镜 / 5 管 OTA，插入即自动成组，可整体拖动摆放；导出支持 SVG / PNG（均可选透明背景）与 PDF（白底）。
  • 选中连线后可直接拖动某一水平/垂直段平移（相邻段自动伸缩）；双击器件/功能块编辑文字标签。
  • 器件移动吸附 10px 网格；「对齐/均布」需选中 ≥2 / ≥3 项。
