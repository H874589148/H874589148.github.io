电路示意图编辑器

面向论文绘图的轻量原理图编辑器：Razavi 教材风格器件库（62 种器件，10 个分类）、10px 网格吸附、端口吸附连线（正交 / 斜线可切换），内置差分对 / 电流镜 / 五管 OTA / 套筒 / 折叠共源共栅模板，一键导出论文级 SVG / PNG / PDF。所有编辑自动保存在本地浏览器。

快捷键与操作：

  • W 连线模式 / T 自由文字标注 / I 弹出器件选择器 / F 适应内容 / U 撤销 / Esc 回选择模式或取消连线。
  • Ctrl+A 全选 / Ctrl+C/V 复制粘贴 / Ctrl+Z/Y 撤销重做 / Del 删除。
  • R 旋转 90°，H/V 水平/垂直镜像；Ctrl+G 成组 / Ctrl+Shift+G 解组；空白处拖拽 = 框选；Ctrl+单击 = 多选。
  • 滚轮缩放（以光标为中心）/ 中键或空格+拖拽平移画布。
  • 插入器件 4 种方式：① Insert 菜单按分类选择 ② I 键弹出搜索面板 ③ 左侧器件库拖入画布 ④ 左侧点击后跟随鼠标放置。
  • 器件库按 Razavi 符号分类分组（可折叠），底部「绘图辅助」含连接点 / 箭头 / 功能块 / MUX；NMOS/PMOS 可在右侧属性栏切换三端教材版 / 四端完整版变体。
  • 「模板」可一键插入差分对 / 电流镜 / 五管 OTA / 套筒 / 折叠共源共栅，插入即自动成组，可整体拖动摆放；导出支持 SVG / PNG（均可选透明背景）与 PDF（白底）。
  • 选中连线后可直接拖动某一水平/垂直段平移（相邻段自动伸缩）；双击器件/功能块/标注编辑文字。
  • 器件移动吸附 10px 网格；「对齐/均布」需选中 ≥2 / ≥3 项。
