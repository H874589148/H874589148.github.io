随机数生成

在指定范围内批量生成随机整数并以卡片展示；或摇一颗骰子，约 3 秒后随机停下。

说明：

  • 范围为闭区间 [min, max] 内的整数（输入自动取整，需 min ≤ max）。
  • 默认允许重复（每次独立均匀抽取）；勾选「不重复」后为不放回抽取，此时要求 n ≤ max−min+1。
  • 数量上限 200；统计行给出个数 / 最小 / 最大 / 均值 / 总和。

点击骰子或按钮开始

说明：标准 6 面骰，数量可选 1~6 颗；点击后面点快速翻滚并逐渐减速，约 2.5~3.5 秒（随机）后同时定格，多颗时附总和。
