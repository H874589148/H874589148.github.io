转换规则：

  • 定点格式：1 位符号 + I 位整数 + F 位小数，总位宽 N = 1+I+F（如 S4.3 表示 I=4,F=3）
  • 真值 = 码值 / 2F，分辨率 = 2-F，范围 [-2I, 2I - 2-F]
  • 正数：原码 = 反码 = 补码（符号位为 0）
  • 负数反码：符号位不变，其余各位取反；补码 = 反码 + 1（最低位）
  • 小数点仅为显示分隔，不占实际存储位
