    说明：

    • 结果保留 12 位有效数字；支持隐式乘法，如 2π、3(4+5)。
    • n! 仅支持 0~170 的非负整数（防止溢出）；ln/log 要求真数 > 0；asin/acos 要求 |x| ≤ 1。
    • DEG/RAD 切换影响三角函数输入与反三角函数输出；± 作用于最后输入的数字。
    • 键盘：数字、+ - * / ^ ( ) !、Enter= 计算、Backspace= 删除、Esc= 清空、P= π。
    • ε、δ、Σ、lim、→ 为记录符号键：插入表达式供随结果一并复制到文档，不参与计算（含符号时按 = 会提示移除）。
