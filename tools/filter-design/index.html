模型假设（工程估算）：

  • 每个电阻的热噪声经主路径 |H(f)| 到达输出（各噪声源功率叠加）。
  • 积分噪声为绘图频段内的数值积分（fref/100 ~ fref×100）；高通类实际带宽受运放限制，结果偏保守。
  • Sallen-Key 采用单位增益 Butterworth 设计（低通等 R、C1=2C2；高通等 C、R2=2R1）。
  • RC-CR 带通忽略级间负载效应；MFB 中频增益固定为 -1、C1=C2。
  • 双 T 带阻：R3=R/2、C3=2C（可用单位件串/并联实现），Q 固定为 1/4，f0 处理想陷波。
  • 面积 = ΣRᵢ/ρR + ΣCᵢ/ρC，仅比较 RC 无源部分，不含运放。

反算结果

幅频特性 |H(f)| (dB)
输出噪声谱密度 √(Σ4kTRᵢ)·|H(f)|（nV/√Hz，对数轴）

模型假设（反算通用式，不假设器件配比）：

  • RC 一阶：fc = 1/(2πR1C1)；SK 低通：H = 1/(1+jωC2(R1+R2)+(jω)²R1R2C1C2)；SK 高通：H = (jω)²R1R2C1C2/(1+jω(R1(C1+C2)+R2C2)+(jω)²R1R2C1C2)。
  • MFB 带通：f0 = √(G12/(R3C1C2))/2π（G12 = 1/R1+1/R2），Q = ω0C1C2R3/(C1+C2)，中频增益 H0 = −C1R3/(R1(C1+C2))；运放按理想（增益带宽 ∞）处理。
  • RC-CR 带通忽略级间负载效应；双 T 带阻按标称配比（R3=R/2、C3=2C），Q 固定 1/4。
  • 噪声口径：en = √(Σ4kTRᵢ)·|H(f)|，ΣRᵢ 为全部电阻之和（双 T 为 2.5R）；积分噪声为绘图频段（fref/100 ~ fref×100）内的数值积分。
