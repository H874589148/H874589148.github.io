波形编辑器

纯图形化数字时序波形绘制：点击改电平、总线填字填色、理想/非理想沿切换、区域填色，SVG/PNG/PDF 导出。

使用说明：

  • 单击槽位选中；电平/时钟行再次点击循环 0 → 1 → Z → X，总线行循环 0 → 1 → 数据块，点击已有数据块弹出文字/颜色编辑面板。
  • Shift + 点击可从当前选中槽扩展选区；「电平与沿」「数据块」「区域填色」组的操作均作用于选区。
  • 「斜坡沿」使选区内的 0↔1 跳变显示为非理想斜线（上升/下降沿），「理想沿」显示为垂直线。
  • 「区域填色」在波形下方绘制半透明色带，用于标注传输窗口等时间段；双击左侧信号名可重命名。
  • 编辑内容自动保存在浏览器本地（localStorage），支持 Ctrl+Z / Ctrl+Y 撤销重做；顶部数字为周期编号（1 周期 = 2 槽）。
