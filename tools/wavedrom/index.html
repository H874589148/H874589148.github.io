波形编辑器（WaveDrom）

数字时序波形编辑器：左侧编辑 WaveJSON，右侧实时渲染；也可以直接在波形图上点击改电平、改数据块文字与颜色、双击重命名信号、右键插入/删除时间槽。

WaveJSON 源码

波形预览（点击槽位切换 0→1→x→z→. ｜ 点击色块改文字/颜色 ｜ 双击名字重命名 ｜ 右键槽位插入/删除）

说明：

  • 本工具基于开源库 WaveDrom（MIT），库文件已本地化（js/vendor/wavedrom.min.js），加载失败时自动回退 CDN。
  • wave 字符串常用字符：0/1 电平、. 保持、x 不确定、z 高阻、p/n 时钟、2~9 数据块（配合 data 数组填文字）、| 时间标记分隔。
  • 高级语法（edge 箭头、phase、period 等）可直接在左侧 JSON 手写，图形编辑与 JSON 实时双向同步。
