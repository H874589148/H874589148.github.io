## 0. 改造前的问题

| # | 现状（代码位置） | 问题 |
|---|---|---|

## 一、需求口径（已与用户确认）

1. 每个零点、极点**独立**支持「直接输入频率 / RC 换算」两种模式。
2. RC 中的 R 指节点**等效电阻**（正实数），C 指对应等效电容，按 `f = 1/(2πRC)` 换算一阶拐点；不做复阻抗、多节点电路推导，也不自动判断某电路是否产生该零点（零点由用户确认电路确实存在）。
3. 「单位增益带宽」= 当前 H(jω) 的 **0 dB 下降交越频率**；不等同于 −3 dB 带宽，也不是增益带宽积 GBW。
4. 相位裕度按 `PM = 180° + φ(fc)` 显示；其工程意义以输入 H 为**负反馈环路增益**为前提，任意开环传函的 PM 仅是几何量。

## 二、功能设计

### 1. 幅频纵轴与网格自适应

- 依据响应数据范围与画布高度自动生成刻度：步长从 `1、2、5 × 10ⁿ dB` 中选取，保持约 5～8 个主区间。
- 上下界向刻度取整并留适当余量；覆盖 >100 dB 与 <−100 dB 场景。
- 0 dB 在显示范围内时加粗突出；不为显示参考线而压缩高增益曲线。
- 纵轴单位独立标注；左 padding 按最宽刻度标签（如 `-120dB`）预留，避免三位数/负数刻度被裁切。
- 相位轴保留默认范围，但曲线超界时自动扩展，不再硬截断。

### 2. 频率范围输入与对数滑块

起止频率改为带单位文本输入，统一换算为 Hz：

| 输入示例 | 实际频率 |
|---|---:|
| `10k`、`10 kHz` | 10 000 Hz |
| `2.5MHz`、`2.5e6` | 2 500 000 Hz |
| `1GHz`、`1e9 Hz` | 1 000 000 000 Hz |

交互：

- 起点、终点各配一条**对数滑块**（相同滑动距离 = 相同频率倍数）。
- 滑块量程默认 **1 mHz ～ 1 THz**；手输合法值超量程时按十倍频程自动扩展量程。
- 默认绘图范围仍为 **1 Hz ～ 100 MHz**。
- 输入框 ↔ 滑块 ↔ 图表三方同步；拖动过程合并重绘（rAF 节流）。
- 严格要求 `0 < 起点 < 终点`；空值、未知单位、溢出、范围倒置均**就地提示**，不再静默替换。
- 输入未完成时保留最后有效图，并提示「参数未生效」；裕度、标记与鼠标取点共用最后有效快照。
- 数值安全边界：频率、R、C 的 SI 数值及 RC 计算结果限定为 1e-150～1e150；起止频率对数间隔至少 1e-8。超界明确报错。增益限定 |dB| ≤ 1e6，V/V 必须为有限正数。

布局：左栏 300px → **360px**；本页容器最大宽度 1200px → **1360px**；≤900px 保持上下堆叠。

### 3. 零极点输入增强（直接频率 / RC 换算）

每行零点/极点提供两种模式切换：

**直接频率**
- 与频率范围同一套解析规则：工程后缀（k/M/G/T 与 m/u/n/p/f，大小写区分 M=Mega、m=milli，兼容 u/μ/µ）+ 科学计数法。
- 支持亚 Hz 值；展示时保留有效数字，不再被 `toFixed(0)` 显示成 0。

**RC 换算**
- 输入等效电阻 R 与等效电容 C，实时显示 `f = 1/(2πRC)` 并更新曲线。
- 支持 `10kΩ`、`1MΩ`、`10pF`、`2.2nF`、`1e-12 F` 等写法。
- R、C 空白时显示「待输入」及缺失字段，不标红；非空值必须为有限正数，否则该字段标红。参数未填齐或非法时不应用旧频率，保留最后有效图及读数。
- 保留已输入的 RC 参数；切回频率模式时带入换算出的频率。首次进入 RC 模式不虚构 R、C 数值。

示例：`R = 10 kΩ, C = 10 pF → f ≈ 1.59155 MHz`。

说明文案：节点 RC 通常对应**极点**估计；仅当电路确实存在该 RC 零点时才用于零点输入。本次不扩展 RHP 零点、共轭根与多节点自动推导（如需请用「传递函数计算」模块画电路）。

### 4. 0 dB 交越与相位裕度图上标注

**幅频图**
- 每个 0 dB 交点绘制标记 + 竖向虚线，标注 `fc/UGB` 与频率。
- 多个交越点全部保留并编号；默认突出**最低频的下降交越点**，其余交越的频率与上升/下降方向列在图下小表，避免标签堆叠。

**相频图**
- 在同一 `fc` 处标出相位值。
- 绘制 −180° 参考线，以及 −180° → `φ(fc)` 的竖向差值标记，注明 `PM` 数值；保留负裕度符号。
- 图上标记与图下裕度摘要共用同一份计算结果，避免两处数值不一致。

**算法与边界**
- 交点在对数频率区间内做细分求根（二分/线性插值混合），不依赖固定 500 采样点的粗插值。
- 全频段恰为 0 dB：提示「无唯一交越频率」。
- 当前范围内无交越：显示「当前频率范围内未找到交越，请检查频率范围」，**不再显示「稳定」或 ∞ 裕度**。
- TF 表达式导入涉及原点根、共轭复根、右半平面根的既有近似：图表与裕度结果明确标注「基于近似模型」，不作实际系统稳定性结论。
- 高频、高阶因子幅值改为对数域累加（Σ 20·log₁₀），降低连乘溢出/精度风险。

## 三、实现范围与兼容性

- 修改 `tools/bode-plot/` 三件套；`bode-core.js` 负责解析、RC、对数域响应、刻度与交越，`bode-plot.js` 负责 Canvas 显示，`tests/bode.test.js` 为无第三方依赖的 Node 回归测试。
- 保留原「陷波」预设的数值，但明确标为原简化预设：其一阶实因子相消后是单极点低通，不是实际陷波；双交越验收使用下述明确参数。
- 保留：Canvas 手绘风格、预设（单极点/Type-II/III/陷波）、TF 表达式导入、零极点标记、鼠标取点读数。
- 新增标记与参考线使用 CSS 变量/主题色适配明暗主题；窗口 resize 后重绘并同步取点坐标。
- 不改全站公共 `parseEngineering()`（其 m/M 语义含糊），本页内置严格解析器；不引入新第三方依赖，遵守站点技术栈约定。

## 四、验收标准（可判定清单）

1. 直流增益 120 / 160 / 200 dB 三档：纵轴刻度完整、标签无裁切、0 dB 线可见（在范围内时）。
2. `1MHz` 与 `1e6` 解析结果一致；`1mHz` 与 `1MHz` 正确区分；`1.2M` ≠ `1.2m`。
3. RC 换算与直接输入同频率时，两条响应曲线逐点一致（采样点 |Δ| < 1e-9 dB）。
4. 基准回归：K=20 dB、单极点 fp=10 kHz → fc ≈ 99.4987 kHz，PM ≈ 95.7392°。
5. 双交越系统：K=20 dB，极点 1 Hz / 10 kHz，零点 100 Hz / 100 Hz，范围 1 mHz～10 MHz；应有下降交越 ≈10.0514 Hz、上升交越 ≈994.886 Hz，突出第一个；图下列表完整。
6. 单极点基准范围改为 1 Hz～1 kHz：提示「未找到交越」，不输出「（稳定）」或「∞」裕度结论；允许说明「不能据此判定稳定性」。
7. K=60 dB，三个极点均 100 Hz、无零点，范围 1 mHz～1 MHz：相位轴扩展并覆盖接近 −270° 的响应；fc≈994.987 Hz、PM≈−72.78°，图上差值保留负号。
8. 非法输入（空、`abc`、`1.2X`、起点≥终点）：就地报错且曲线保持上次有效状态。
9. 滑块从 1 mHz 连续拖到 1 THz：无卡顿，松手后输入框值与图一致。
10. 暗色主题下网格、标记、读数框对比度可读；窄屏（<900px）布局为单列且无横向溢出。
11. `node --check` 与新增回归测试全部通过；控制台零报错。
12. 实现后先自测，再由低消耗模型执行浏览器逐项校验；差异记录后回到高性能模型修改；全程不提交 Git。
