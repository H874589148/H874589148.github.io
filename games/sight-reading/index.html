识谱练习

看谱按键 · 37 个章节覆盖 88 键全部组别与十五个大调 · 学习 / 自由测验 / 限时挑战

覆盖 88 键全部 9 个组别，从中央 C 向两端展开；极端音区按 8va / 8vb / 15ma 记谱。

G / D / A / E / B / F♯ / C♯ 大调：按调号升高的音，黑键主音章节键盘从黑键起排。

F / B♭ / E♭ / A♭ / D♭ / G♭ / C♭ 大调：按调号降低的音。

88 键总览 · 高亮为本章音域

玩法与规则说明：

  • 学习模式：按局部键盘（或电脑键盘）任意琴键，谱面上显示对应音符并标注音名与唱名，同时发声。
  • 自由测验：每页 10 个音符，从左到右逐个按对即消失，按错抖动提示不扣分；整页完成后自动出下一页。
  • 限时挑战：60 秒内按对越多分越高，每页 8 个音符，成绩自动记录为本章最佳。
  • 章节体系：第一部分 C 调覆盖 88 键全部 9 个组别（大字二组 A0–B0 至小字五组 C8）；第二、三部分为升号调 / 降号调大调，每调含高音、低音谱号各一章，音域为主音到七级音的一个八度。
  • 八度记谱：小字三组及以上用 8va / 15ma（谱面写在下方八度，实音升高）、大字一组及以下用 8vb（实音降低），按键判定一律按实音；虚线八度线即标记范围。
  • 调号：谱面升降号按调号作用于对应音级，如 G 大调的 F 音需按 F♯（黑键）；测验只出现调内音级。
  • 电脑键盘映射：白键从左到右 ASDFGHJ，黑键从左到右 WETYU，键位随章节音域自动平移，键盘上已标出对应字母。
  • 不完整组别：大字二组仅 A0–B0 三键、小字五组仅 C8 单键，局部键盘以 12 键视窗展示，窗外琴键置灰不可按。
